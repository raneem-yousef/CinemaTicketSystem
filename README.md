# Cinema Ticket System

A desktop-based cinema ticket management system developed using **Java Swing** and **Apache Derby Database**.

## Features

* Admin and Customer login
* Customer registration and profile management
* Movie management
* Movie search
* Ticket booking
* Ticket information management
* Customer ticket lookup
* Movie pricing and show time selection

## Technologies

* Java
* Java Swing
* JDBC
* Apache Derby Database
* NetBeans IDE
* SQL

## Database

The system uses Apache Derby Database with the following main tables:

* `USERS`
* `CUSTOMERS`
* `MOVIES`
* `TICKETS`

## Project

This project was developed as a university project to practice building a database-driven desktop application using Java, GUI development, JDBC, and SQL.
